Etapas do aprendizado de máquina

♡
  1. 1
    Recebe dados históricosOcupação, atendimentos, internações, altas e dia da semana.
  2. 2
    Treina uma regressãoAjusta os parâmetros para relacionar os dados de entrada à ocupação do dia seguinte.
  3. 3
    É avaliadoUma parte final dos registros fica separada para medir o erro em dados não usados no ajuste.
  4. 4
    Faz a estimativaUsa os dados atuais e as variáveis informadas para estimar os próximos dias.
